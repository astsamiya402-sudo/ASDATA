# ASDATA Backend

Backend server for the ASDATA Android app and VTUGATE integration.

## Features

- Fetch VTUGATE data plans
- Buy data through VTUGATE
- Keep the VTUGATE API key on the server
- Basic request validation
- CORS protection
- Basic rate limiting
- Health-check endpoint

## Requirements

- Node.js 18 or newer
- VTUGATE API key
